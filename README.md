# Carbon Footprint Site

Static, single-file HTML/CSS/JS pages — no build step, no backend. Open any file directly in a browser, or serve the folder as a static site. All data is stored in the browser's `localStorage`.

- **carbon-report.html** — Research & module plan report (Scope 1/2/3, current-module audit, proposed 8-module app, AI roadmap, phased plan).
- **carbon-mvp.html** — Working Phase 1 + 2 prototype: org/site setup, Scope 1/2/3 activity entry, supplier questionnaire portal, CSV import + simulated ERP sync, and BRSR Core / GHG Protocol report exports.
- **carbon-ledger.html** — Personal carbon footprint tracker (transport, home energy, food, goods & waste).
- **foodprint.html** — Food-only carbon tracker with a 14-day trend, food-group breakdown, and daily swap suggestions.
